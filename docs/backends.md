# Backends and data egress

A backend answers typed decision requests. The core protocol provides boolean,
choice, and score shapes for forward compatibility; only boolean is required by
the v0.1 equality MVP.

## Fake backend

`FakeBackend` is deterministic and in-process. It is the default choice for
tests, examples, record/replay fixtures, and evaluating application control flow.
It performs no network requests and requires no API key. Configure every
state/proposition pair the program will ask about so missing fixtures fail
clearly rather than becoming an accidental `False`.

## Laya

Laya is the primary local backend. Its adapter follows the same typed decision
protocol as the fake backend, but it is not part of the offline path. OpenAI is
available separately as an experimental hosted backend. Do not assume that a
model is private merely because inference is local:
verify installation-time and runtime downloads, subprocesses, telemetry,
license, credentials, and data handling against the current Laya implementation
before use.

Before enabling Laya:

1. Verify its current API, license, maintenance status, quality, and latency.
2. Pin or record the provider and model version.
3. Read its retention, training-use, region, and subprocess/network behavior.
4. Load credentials from environment or secure runtime configuration, never
   from source control.
5. Make live tests opt-in; offline tests must remain independent of credentials,
   paid services, and network access.

Install the optional integration with `pip install 'semantic-python[laya]'`.
Laya currently uses a `Router().predict` API with noul questions. Its first
prediction downloads model checkpoints, and its dependency stack includes
PyTorch and Transformers, so plan for download time, disk space, memory, and
cold-start latency. Upstream also warns that the base English noul/negation
behavior can be unreliable. Validate it on representative domain data and never
use it as high-impact authorization.

```python
from semantic_python import LayaBackend, Semantic, configure

configure(backend=LayaBackend(), threshold=0.85)
decision = Semantic("I'm done") == "the user wants to stop"
```

Unlike the fake examples, this can download large artifacts, consume substantial
local resources, take materially longer, and vary between model versions.

Configuration must make remote transfer explicit. Merely importing
`semantic_python` or constructing a `Semantic` value must not send data.
Applications should disclose data egress to their users and avoid sending
secrets or regulated information unless the full deployment is approved for it.

Backend failures and timeouts are errors, not negative classifications. A
fallback or cascade must be explicitly configured and must retain provenance so
callers can tell which backend actually supplied the answer.

Synchronous `==` can block when backed by model inference. Avoid it on an event
loop or latency-sensitive path until an explicit async API is available.

## OpenAI

`OpenAIBackend` is an experimental hosted integration using strict Structured
Outputs through the Responses API. It defaults to `gpt-6-luna`, which is aimed
at focused, high-volume tasks. Install it with
`pip install 'semantic-python[openai]'`, provide `OPENAI_API_KEY` through the
environment, and select it explicitly:

```python
from semantic_python import OpenAIBackend, Semantic, configure

configure(backend=OpenAIBackend(), threshold=0.85)
decision = Semantic("I'm done") == "the user wants to stop"
```

The comparison transmits the complete semantic state and proposition to OpenAI
and may incur latency and cost. The returned probability is generated by the
model and always represents `P(proposition=true)`, rather than confidence in
the selected Boolean. The adapter rejects a response whose Boolean conflicts
with that probability. The estimate is retained as
`confidence_kind="model_reported"` and must not be treated as calibrated
without evaluation on representative application data.
Importing `semantic_python` or constructing a `Semantic` value does not make a request.

Jev, Kev, AnyJev, other hosted providers, and arbitrary custom-provider
integrations remain roadmap research only.
